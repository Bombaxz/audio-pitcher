Privacidad

Última actualización: 19 de octubre de 2026

El programa

Audio Pitcher no tiene cuentas ni recopila datos personales. El audio se procesa en tu PC y nunca se envía a ningún servidor. Tu configuración (tema, colores, apps favoritas) se guarda solo en tu equipo.

Al abrirse, el programa consulta la API pública de GitHub para saber si hay una versión nueva. Esa consulta no incluye ningún dato tuyo más allá de lo que cualquier conexión a internet expone, como la dirección IP.

Este sitio

El sitio puede usar herramientas de medición de visitas (como Google Analytics o Microsoft Clarity) y anuncios de Google AdSense. Estos servicios pueden usar cookies para contar visitas, entender cómo se usa la página y mostrar anuncios. Puedes bloquear o borrar las cookies desde tu navegador.

La descarga del instalador se sirve desde GitHub, que tiene su propia política de privacidad.
